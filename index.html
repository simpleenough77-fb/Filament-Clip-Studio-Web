A header row is optional. Columns must be in the order manufacturer, filament type, color/name, quantity. The CSV import action above decides whether rows are added or replace the batch.

CSV columns: manufacturer, filament_type, color_name, quantity. The official catalog is maintained by the author.

Prefer a guided import? Use the Google Sheets CSV builder link at the top of this page. It makes your own copy of the sheet, where you choose valid manufacturer, filament type, and color combinations. Then copy its rows into Paste rows, or download the CSV and use Import CSV.

2. Style the batch

Holder sleeves require supports. Clips with sleeves print text-side down. The project includes tested support painting and tunnel support blockers. Check the support preview and filament settings before printing.

Automatic manufacturer and color sizes are 80% of the type size. Choose shared filaments in the slicer, or use the filament named on each label. Actual Filament uses catalog swatches, including approximate gradients and effects. Shared bodies default to black with Bambu Green text. Contrasting Filament selects light or dark text when the body uses Actual Filament. Assign the actual filament presets in the slicer.
